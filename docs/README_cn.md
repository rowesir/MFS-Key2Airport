# Key2Airport

🌐 [简体中文](README_cn.md) · [English](../README.md)

K2A 是 Microsoft Flight Simulator 的按键绑定辅助工具。
它可以监听键盘、鼠标和游戏控制器的输入，并按照 JSON 配置向飞机发送按钮事件。

## 1. 连接和基本使用

1. 启动 Microsoft Flight Simulator。
2. 启动 K2A。
3. 在主界面选择配置方式：
   - 勾选自动配置时，程序会根据当前飞机自动选择对应的 JSON 配置；
   - 不勾选自动配置时，在下拉框中手动选择配置文件。
4. 建议在进入生涯模式、自由飞行等正式飞行之前点击 `Connect`。
5. 进入飞行后，状态显示为 `Aircraft Loaded`，此时可以使用 `Enum` 和 `Test`。

### 配置和刷新

配置文件位于程序目录下的 `config` 文件夹中，点击 `Folder` 可以打开该文件夹。

使用自动配置时，如果没有找到当前飞机对应的 JSON 文件，程序会自动生成一个基本的 JSON 配置框架。用户可以打开这个文件，填写自己的 Hash 和按键规则。

修改配置文件后，在飞行中点击主界面的刷新按钮（循环箭头图标），程序会重新读取当前配置。自动配置模式会重新载入当前飞机对应的文件；手动配置模式会重新扫描并载入当前选择的文件。

状态含义：

| 状态 | 含义 |
| --- | --- |
| `Standby...` | 尚未连接 |
| `Waiting MFS...` | 正在等待模拟器或重新连接 |
| `Connected` | 已连接模拟器，但尚未进入正式飞行 |
| `Aircraft Loaded` | 已进入正式飞行 |

软件启动后会自动监听输入。按下键盘或外设按键时，主界面的按键名称区域会显示名称，例如：

```text
V
NUM 7
L CTRL+B
Mouse Wheel Up
```

配置文件中的按键名称必须与这里显示的名称一致。

### 避免与游戏原有按键冲突

本工具使用的按键，需要先在模拟器的控制设置中移除对应的原有绑定。
否则游戏自身的绑定和 K2A 可能会同时响应同一个按键。

具体 JSON 配置可以参考发布文件中的 `SF50` 模板（不同用户的 Hash 值可能不同）。该模板示例包括：

| 配置位置 | 实体按键 | 功能 |
| --- | --- | --- |
| 页面切换 | `NUM -` | 切换配置页 |
| 配置表一 | `L CTRL+V` | 按下 VNAV 按钮 |
| 配置表一 | `[` | 修正海压旋钮左旋转 |
| 配置表一 | `]` | 修正海压旋钮右旋转 |
| 配置表一 | `L SHIFT+[` | 按下修正海压旋钮 |
| 配置表二 | `B` | 开启或关闭着陆灯 |

飞行结束后可以点击 `Disconn` 断开连接。若仍在飞行中手动断开或关闭窗口，程序会弹出确认提示。

## 2. RA 和 LR

| 选项 | 用途 |
| --- | --- |
| `RA`（Radio Altitude） | 读取并显示无线电高度；有可用音频设备时可进行语音播报 |
| `LR`（Landing Rate） | 记录并显示飞机接地时的接地率 |

这两个选项可以在连接前设置，也可以在配置文件中设置默认值：

```json
"RA_CHECKBOX": true,
"LR_CHECKBOX": true
```

## 3. Enum、Listen 和 Test

进入正式飞行、状态显示为 `Aircraft Loaded` 后，`Enum` 和 `Test` 按钮才可以使用。

推荐使用顺序：

1. 使用 `Enum` 查找当前飞机的事件名称和 Hash；
2. 使用 `Listen` 在游戏中实际操作按钮，确认事件的 Hash、参数类型和参数值；
3. 使用 `Test` 读取或发送数值，确认事件可以正常使用；
4. 将确认后的 Hash 和数值填写到 JSON 配置中。

### Enum

点击 `Enum`，程序会枚举当前飞机可以使用的全部 InputEvent。

在全部枚举表中可以查看事件的名称和 Hash。`Filtra` 输入框可以按事件名称进行过滤，过滤时不区分大小写。

### Listen

打开 Enum 窗口后，程序会同时监听游戏内发生的 InputEvent。

可以在游戏中用鼠标点击按钮、开关或操作控件，然后在 Listen 表格中查看对应的：

- Hash
- 参数类型
- 参数值
- 参数大小
- 最近变化时间

通过 Enum 找到事件名称，再通过 Listen 观察实际操作得到的 Hash 和参数信息，可以帮助确定要绑定的按钮事件。

### Test

`Test` 用于测试某个 Hash 的值：

1. 输入十进制 Hash；
2. 点击读取，查看当前值；
3. 输入数值并点击发送，测试该事件是否能被正确设置。

目前 Test 和 JSON 配置主要支持参数类型为 `DOUBLE` 的事件。

### 测试环境

- Microsoft Flight Simulator 游戏版本：`1.8.16.0`
- Microsoft Flight Simulator SDK 版本：`1.7.3`

## 4. JSON 配置

配置文件放在程序目录下的 `config` 文件夹中，文件必须是标准 JSON，不能使用 `//` 或 `/* */` 注释。

一个最基本的配置结构如下：

```json
{
  "AIRCRAFT": "SF50",
  "RA_CHECKBOX": true,
  "LR_CHECKBOX": true,
  "PAGESWITCH": "NUM -",
  "VARIABLES": [
    { "vnav": "1234567890" }
  ],
  "PAGE_1": {
    "V": [
      { "THEN": "vnav = 1" }
    ]
  },
  "PAGE_2": {}
}
```

### 顶层字段

| 字段 | 用途 |
| --- | --- |
| `AIRCRAFT` | 配置对应的飞机名称 |
| `RA_CHECKBOX` | 是否默认启用 RA |
| `LR_CHECKBOX` | 是否默认启用 LR |
| `PAGESWITCH` | 页面切换按键名称，留空表示不使用 |
| `VARIABLES` | 自定义变量名与 Hash 的对应关系 |
| `PAGE_1` | 第 1 页的按键规则 |
| `PAGE_2` | 第 2 页的按键规则 |

### VARIABLES

把 Hash 保存为字符串，并给它起一个容易记忆的变量名。Hash 可以从 Enum、Listen 或 Test 页面获得。
变量名可以使用字母、数字和下划线，但不能以数字开头。

```json
"VARIABLES": [
  { "vnav": "1234567890" },
  { "hdg": "9876543210" }
]
```

之后就可以使用 `vnav`、`hdg` 这些变量名，不需要在每条规则中重复填写 Hash。

### 按键和规则

`PAGE_1` 或 `PAGE_2` 中的字段名就是按键名称，值是规则数组。按键名称必须与主界面显示的名称完全一致：

```json
"V": [
  {
    "THEN": "vnav = 1"
  }
]
```

按下 `V` 时，程序会向 `vnav` 对应的 Hash 发送数值 `1`。

每条规则可以使用以下字段：

| 字段 | 用途 |
| --- | --- |
| `IF` | 条件，可选；没有 `IF` 时直接执行 `THEN` |
| `THEN` | 条件成立时执行的内容 |
| `ELSE` | 条件不成立时执行的内容，可选 |

同一个按键可以包含多条规则，程序会按照 JSON 中从上到下的顺序执行。

### 条件写法

条件可以使用变量、数字、比较符和逻辑符：

```text
==   >=   >   <=   <
&&   ||
```

例如：

```json
"IF": "vnav == 1 && hdg == 0"
```

也可以使用括号。计算顺序为：括号、比较、`&&`、`||`。

目前不支持 `!=` 和加减乘除等算术表达式。

### 执行写法

执行内容为“变量名 = 数字”：

```text
vnav = 1
```

多个操作使用分号分隔，并按照从左到右的顺序执行：

```json
"THEN": "vnav = 0; hdg = 1"
```

最后一个操作后面的分号可以省略，也可以保留。

右边只能填写数字，不能填写另一个变量或计算式。

### 常用示例

直接发送：

```json
"V": [
  { "THEN": "vnav = 1" }
]
```

按当前值切换开关：

```json
"NUM 7": [
  {
    "IF": "gearLight == 1",
    "THEN": "gearLight = 0",
    "ELSE": "gearLight = 1"
  }
]
```

页面切换：

```json
"PAGESWITCH": "NUM -"
```

按下 `NUM -` 后，会在 `PAGE_1` 和 `PAGE_2` 之间切换。
使用不同的配置页，可以让同一个实体按键在不同页面绑定到不同的飞机按钮或旋钮。

## 注意事项

- 建议在进入正式飞行前连接软件；如果进入飞行后才连接，可能无法收到本次进入飞行的通知。
- 配置发送和读取目前以 `DOUBLE` 类型 InputEvent 为主。  
- 飞机内大部分旋钮在获取对应 Hash 后，可以尝试使用 `-1` 表示向左旋转、`1` 表示向右旋转；不同飞机或不同旋钮可能存在差异。             
- 某些拨杆开关（例如灯光开关）使用 `0` 表示关闭、`1` 表示开启。将它绑定到一个按键时，可以使用条件语法实现切换：

  ```json
  "IF": "light == 1",
  "THEN": "light = 0",
  "ELSE": "light = 1"
  ```

- 绝大部分点按式开关只需要发送 `1` 就可以切换，具体效果请用户根据实际飞机自行尝试。
- 本软件目前只在 Microsoft Flight Simulator 2024 的西锐 G2（SF50）上进行过验证，其他飞机以及插件机尚未测试。
- JSON 中的 Hash、按键名称和变量名需要填写正确，否则对应规则无法正常执行。
